# Holmerud homelab

Interactive 3D layout for a FRITZ!Box 6660 Cable, two Raspberry Pi 4 (Geekworm P173), four SSDs on a powered hub and a Home Assistant Connect ZBT-2 on an IKEA HOLMERUD side table, with every cable routed and clipped (IKEA TRIXIG).

- `index.html`: open in any browser.
- `src/holmerud.html`: source. Table geometry and the oak texture come from the HOLMERUD SketchUp model.
- `python3 build.py`: rebuilds `index.html` and `artifact.html` with the texture inlined.
